Rocket.Chat Developer documentation has been moved to [http://developer.rocket.chat/](http://developer.rocket.chat/)

### Summary

Rocket.Chat is an open-source communication platform that allows teams to collaborate and communicate in real-time. It provides features like chat rooms, file sharing, video conferencing, and integrations with various tools and services. As a self-hosted solution, Rocket.Chat ensures data privacy and security, making it a versatile choice for organizations requiring robust and customizable communication channels.
